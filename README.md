# Privacy policy — Life Organizer

Questo repository contiene **solo** l'informativa sulla privacy dell'app, pubblicata tramite GitHub
Pages. Il codice sorgente dell'app sta altrove, in un repository privato: qui è pubblico soltanto
ciò che deve esserlo per forza.

Google Play richiede che ogni app abbia un'informativa raggiungibile a un **URL pubblico e stabile**,
anche quando — come in questo caso — l'app non raccoglie alcun dato.

## Prima di pubblicare

Nella pagina ci sono due segnaposto, evidenziati in giallo perché sia impossibile non vederli:

- `[INSERIRE LA DATA DI PUBBLICAZIONE]`
- `[INSERIRE L'INDIRIZZO EMAIL]`

L'indirizzo email **compare pubblicamente** anche sulla scheda dello store: conviene che sia un
indirizzo dedicato all'app, non quello personale.

## Come pubblicarla

1. Crea su GitHub un repository **pubblico** (per esempio `life-organizer-privacy`).
2. Collega questa cartella e spingi il ramo `main`.
3. Nel repository: *Settings → Pages → Source: Deploy from a branch → `main` / `(root)`*.
4. Dopo un minuto la pagina è online. L'URL sarà nella forma
   `https://<utente>.github.io/<nome-repository>/`.
5. Quell'URL va incollato in Play Console, nella scheda dello store e nel modulo Data Safety.

## Quando andrà aggiornata

⚠️ **Quando l'app avrà account e sincronizzazione cloud, questa informativa diventa falsa.** Da quel
momento verranno raccolti un indirizzo email e i dati inseriti, conservati su un server.

L'informativa va aggiornata **prima** che quella versione dell'app venga pubblicata, insieme al
modulo Data Safety di Play: una dichiarazione non veritiera è motivo di rimozione dell'app, non di
un semplice richiamo. Il dettaglio di cosa cambierà è annotato nel repository dell'app, in
`docs/08-privacy-e-store.md`.
